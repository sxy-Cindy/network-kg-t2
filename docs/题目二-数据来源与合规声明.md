## 一、声明

本组郑重声明：

1. 本作业**仅使用**下列公开数据源，未抓取、未使用任何需要登录、付费、授权或
   违反服务条款的内容。
2. 本仓库**不包含**推荐性国家标准（GB/T）全文、实验室设备配置、自采日志，
   也不包含任何真实口令、密钥、凭据或内网地址。
3. 原始下载数据（`data/raw/`）与 LLM 调用缓存（`data/llm_cache/`）不进入版本库，
   由 `scripts/fetch_t2_data.py` 与 `kgc.llm_t2` 重新生成；仓库仅保留可公开的
   派生语料、抽取结果与评测产物。
4. Sigma 规则**只使用元数据**（UUID、标题、标签、描述、等级），不复制检测逻辑
   正文，符合 Detection Rule License (DRL) 1.1。
5. 使用 ATT&CK、CWE、CAPEC、EPSS 时遵守各自署名要求；本报告与仓库 README
   均标注来源。
6. 本作业产物仅用于课程学习与评估，不用于商业分发。

提交前已运行 `tools/check_restricted_data.py`，结果：**高风险 0 项，中/低风险 0 项，
